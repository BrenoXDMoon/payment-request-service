# payment-request-service








### Declaração de uso de IA
Este projeto utilizou ferramentas de IA para auxiliar na geração de código, documentação e planejamento arquitetural. A seguir, detalho o uso específico de IA durante o desenvolvimento:
- **Ferramenta de IA utilizada:** Claude Code
- **Prompts principais enviados:** 
  - Solicitação de um plano de implementação passo a passo, incluindo estrutura de pacotes, modelagem do agregado "Solicitação de Pagamento", eventos de domínio, endpoints REST, estratégia de persistência no MongoDB, tópicos Kafka e formato do contrato de mensagens, estratégia de testes, pontos de observabilidade e o que seria mockado/simulado.
  - Solicitação de revisão e sugestões para a modelagem dos estados da solicitação de pagamento.
  - Solicitação de exemplos de contratos OpenAPI/Swagger para os endpoints REST.
  - Solicitação de exemplos de logs estruturados e métricas mínimas para observabilidade.
